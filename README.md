# GitHub Pages Portfolio Starter

A dependency-free personal portfolio built with HTML, CSS, and vanilla JavaScript.

## Edit first

Search the whole folder for:

- `Your Name`
- `YN`
- `YOUR_USERNAME`
- `YOUR_LINKEDIN`
- `you@example.com`
- `YOUR_REPOSITORY`

Replace the project titles, descriptions, tags, and project detail content.

## Local preview

From this directory:

```bash
python3 -m http.server 8000
```

Then open:

http://localhost:8000

## GitHub Pages

Create a GitHub repository named:

YOUR_USERNAME.github.io

Push these files to the `main` branch, then enable GitHub Pages from the repository settings using the `main` branch and `/(root)` folder.
